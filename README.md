# FisherAI-PLUS

基于 [fisherdaddy/FisherAI](https://github.com/fisherdaddy/FisherAI) 的**改进增强版** Chrome 扩展（Manifest V3）。

## 与原版的差异（新增/修复）

| 功能 | 说明 |
|---|---|
| 🎬 **视频画面总结**（新增第 4 张卡片） | 针对"画面贴字 + 纯 BGM"类视频：抽取视频画面 → 视觉大模型理解内容，无需字幕。时间轴使用 B站 播放器官方 `pvdata.bin` 权威时间轴，精确到秒 |
| 💾 **侧窗对话持久化** | 关闭侧窗/浏览器重启后，对话、上下文、进度原样恢复 |
| 📄 **Markdown 导出** | 一键把当前对话导出为 .md 文件（含页面地址、时间） |
| 🧹 **上下文隔离** | 摘要/画面总结等单发任务不再串扰上个视频的内容 |
| 🌐 **YouTube 字幕修复** | 自动取视频自带字幕轨（不再硬编码英文导致中文视频读取失败） |
| 📌 **界面精简** | 移除网页翻译/视频翻译卡片与划词翻译；新增显式"新聊天"按钮、悬停提示、标准分享图标 |
| ⚙️ **长任务健壮性** | 请求超时 180s→600s；`max_tokens` 支持按次覆盖；思考块默认折叠；截断检测 |

## 安装（开发者模式）

1. 克隆/下载本仓库到本地
2. 打开 `chrome://extensions` → 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选择本仓库目录
3. 进扩展设置配置 API Key：支持 DeepSeek / Gemini / 硅基流动 等供应商（**画面总结需选择视觉模型**，如 `deepseek-v4-flash-vision-exp`）

## 使用场景

- **智能摘要**：网页 / PDF / B站 / YouTube 视频字幕总结
- **画面总结**：贴字视频、无字幕视频（选视觉模型后点第 2 张卡片）
